# Asset Sources

This file records the provenance of the texture assets distributed with
Oxygen Atmosphere. It supplements the project license and does not replace the
MakeUp Ultra Fast credits in `README.md`.

## OpenAI-generated project assets

The following original visual assets were generated for this project with
OpenAI image-generation tools. Under the applicable OpenAI terms, the project
owner owns the generated output as between the owner and OpenAI, subject to
applicable law:

- `shaders/textures/moon_dynamic_albedo_4096.png`
- `shaders/textures/oxygen_atmosphere_sun_4096.png`
- `shaders/textures/oxygen_atmosphere_water_height_source.png`
- `shaders/textures/oxygen_atmosphere_water_dawn_height_source.png`
- `shaders/textures/oxygen_atmosphere_water_dusk_height_source.png`
- `shaders/textures/oxygen_atmosphere_water_night_height_source.png`

The water height-source images retain embedded C2PA Content Credentials from
OpenAI. The sun and moon provenance is recorded here from the project owner's
creation record even though those exported PNG files do not retain embedded
C2PA metadata.

The following textures are project-created derivatives of the generated water
sources above:

- `shaders/textures/oxygen_atmosphere_water_flow_1024.png`
- `shaders/textures/oxygen_atmosphere_water_dawn_flow_1024.png`
- `shaders/textures/oxygen_atmosphere_water_dusk_flow_1024.png`
- `shaders/textures/oxygen_atmosphere_water_night_flow_1024.png`
- `shaders/textures/oxygen_atmosphere_water_cycle_atlas_2080.png`

The matching `.mcmeta` files are project configuration metadata for these
textures.
