# Asset Sources

This file records the provenance of the texture assets distributed with
Cinematic Fog. It supplements the project license and does not replace the
MakeUp Ultra Fast credits in `README.md`.

## OpenAI-generated project assets

The following original visual assets were generated for this project with
OpenAI image-generation tools. Under the applicable OpenAI terms, the project
owner owns the generated output as between the owner and OpenAI, subject to
applicable law:

- `shaders/textures/moon_dynamic_albedo_4096.png`
- `shaders/textures/cinematic_fog_sun_4096.png`
- Four water height-source images (day, dawn, dusk, night). They are not
  shipped in the pack; they are kept in the project owner's records.

The water height-source images retain embedded C2PA Content Credentials from
OpenAI. The sun and moon provenance is recorded here from the project owner's
creation record even though those exported PNG files do not retain embedded
C2PA metadata.

The following textures are project-created derivatives of the generated
assets above:

- `shaders/textures/moon_dynamic_albedo_2048.png` (downscaled moon)
- `shaders/textures/cinematic_fog_sun_2048.png` (downscaled sun)
- `shaders/textures/cinematic_fog_water_cycle_atlas_2080.png` (built from the
  water height sources through intermediate flow maps)

The matching `.mcmeta` files are project configuration metadata for these
textures.

## MakeUp Ultra Fast assets

The following cloud textures and their matching `.mcmeta` files originate from

the attribution preserved in `README.md`:
